# re:desktop

A socket connects a bridge to a shared host. The host binds a private session identity, retains a FIFO queue and issues an epoch per grant. Immediate Pause revokes the grant. Pause after keeps only the current grant and enters Pause when it ends. Connectedness, presence heartbeats and access renewal measure different facts. Confirmed disconnection releases access, while a surviving bridge can remain connected beyond its user's last action. A deadline therefore remains an independent invalidation input.

[Model.lean](Model.lean) projects holder, epoch and deadline after host expiry processing and caller attribution. A matching holder and epoch start a fresh 900000 ms heartbeat window. The separate presence interval is 30000 ms. At clock 100 the historical projection returned 30100 for an accepted renewal. The production result is 900100. Rejection preserves the grant in both versions, which explains why the stale-epoch theorem passed before the fix.

Run `scripts/check` and `scripts/compare-desktop` from the rules root. The comparison emits the upstream Bend core to a local fixture, invokes it directly and through the production in-process coordinator, and compares the observed grant to Lean. It checks accepted renewal, a stale epoch and a second subscribed caller presenting the holder's current token. The host reports `STALE_LEASE` and `NOT_HOLDER` respectively. The fixture exercises the coordinator's public snapshot at a controlled clock. Socket transport, GUI input, timer delivery and deployed services are outside this check.

The comparison also exercises Pause after with no holder, with one holder and a queued successor, and after release. A new caller cannot join while the pause is pending. A previously queued caller retains its position. The host reports whether new grants are allowed independently of whether anyone currently holds access.

The upstream [13 Bend laws](../../re-desktop/LAWS.bend) cover pause, paused scheduling, stale release and renewal, FIFO grant, the accepted heartbeat deadline, and six deferred-pause properties covering preservation, ending, scheduling, release, and cancellation. Run their proof kernel with `(cd ../re-desktop && node scripts/bend.mjs PROOF.bend --verdict)`. [Source pins](../sources.json)
