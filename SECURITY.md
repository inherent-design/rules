# Security

Report sensitive findings through GitHub's private vulnerability reporting for [inherent-design/rules](https://github.com/inherent-design/rules/security/advisories/new). Public issues can discuss non-sensitive model or documentation defects.

Include the source revision, affected rule or adapter, prerequisites, a bounded reproduction, and the observed consequence. Preserve uncertainty about external effects. Use synthetic credentials and isolated data in public reproductions.

This repository contains research models and prototype adapters. Each model's documentation owns its actual evidence and qualification limits.
